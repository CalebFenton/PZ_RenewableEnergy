/*
    Item scripts. Display names come from Translate/<LANG>/ItemName.json and tooltips from
    Tooltip.json. Ratings (watts, watt-hours, cycles) live in lua/shared/RenewableEnergy/Specs.lua,
    not here, so the power code reads one table.

    Every item's Icon is RenewableEnergy_<Item> (common/media/textures/Item_RenewableEnergy_<Item>.png)
    and its WorldStaticModel RenewableEnergy.<Item>_Ground (Models.txt), moveables included: the
    crafting window draws the script's icon, and a moveable without one shows as an empty square.

    base:ignorezombiedensity keeps the zombie density loot bonus, which is added to every entry
    whatever its weight, from swamping the hardware's small loot weights.

    Moveables name the tile they place in WorldObjectSprite (RenewableEnergy.Sprites); each tile
    names its item back in CustomItem, so picking it up returns this item.
*/

    /*

        that a small panel's trickle is not rounded away (uses are whole steps of it).

        The deep cycle battery also fits a vehicle's Battery part (Lua:
        RenewableEnergy.VehicleBattery), where it runs the lights and radio longer with the engine
        off. The L-16 doesn't: it is a 6 V battery, and a car's starter and lights need 12 V.
    */
